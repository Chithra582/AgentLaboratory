# LaTeX Manuscript Generation

## Overview
This skill drafts and compiles full-length, publication-grade academic research papers formatted in standardized conference and journal LaTeX templates (e.g., NeurIPS, ICML, ICLR).

## Key Capabilities
- **Structured Academic Prose**: Authors formal technical sections with clear mathematical notation and scientific clarity.
- **Automated Table Formatting**: Generates clean booktabs LaTeX tables highlighting top-performing metrics with bold formatting.
- **BibTeX Compilation**: Manages citation keys, eliminates duplicate entries, and ensures clean document compilation.

## Operational Workflow
1. **Outline Formulation**: Establish section hierarchy and assign word count budgets.
2. **Drafting Sections**: Sequentially draft Abstract, Introduction, Methods, Experiments, and Discussion.
3. **Asset Integration**: Embed generated vector plots and empirical benchmark tables.
4. **Compilation Verification**: Run multi-pass pdflatex and bibtex pipelines, resolving any formatting warnings.
